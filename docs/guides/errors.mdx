# Errors and token handling

Inspect typed failures with `errors.As` or the helper functions in
`tplinkmodels`; do not parse error strings.

```go
_, err := client.GetDevices(ctx, tplink.GetDevicesRequest{Auth: auth})
if err != nil {
    switch {
    case tplinkmodels.IsTokenExpiredError(err):
        // Log in again and replace the token.
    case tplinkmodels.IsRateLimitError(err):
        // Apply application-level backoff.
    case tplinkmodels.IsNetworkError(err):
        // Inspect the wrapped cause with errors.Is or errors.As.
    }
    return err
}
```

## Cloud errors

The client checks the outer integer `error_code`:

| Code | Typed error | Helper |
| --- | --- | --- |
| `-20004` | `RateLimitError` | `IsRateLimitError` |
| `-20651` | `TokenExpiredError` | `IsTokenExpiredError` |
| `-20104` | `ParameterError` | `IsParameterError` |
| `-20601` | `AuthenticationError` | `IsAuthenticationError` |
| Other nonzero code | `CloudAPIError` | `IsCloudAPIError` |

The optional cloud `msg` is retained. This is the set of special mappings in
the implementation, not a complete provider error catalogue.

## Device errors

`result.responseData` is JSON text. A device failure can have a top-level
`err_code` or be nested under the requested namespace and command. For example,
after decoding the response string:

```json
{"system":{"set_relay_state":{"err_code":-1,"err_msg":"<device-message>"}}}
```

Device `err_code: -1` maps to `tplinkmodels.UnsupportedOperationError`; other
nonzero codes map to `tplinkmodels.DeviceError`. `err_msg` is optional. Missing
namespaces or commands, malformed JSON, and unusable result shapes become
`tplinkmodels.InvalidResponseError`.

## Other failures

| Situation | Error type / helper |
| --- | --- |
| Invalid client setup | `ConfigurationError` / `IsConfigurationError` |
| Request preparation or command JSON encoding failure | `InvalidRequestError` / `IsInvalidRequestError` |
| HTTP status outside 2xx | `HTTPStatusError` / `IsHTTPStatusError` |
| Missing, malformed, or wrong-shaped response | `InvalidResponseError` / `IsInvalidResponseError` |
| Response body larger than 1 MiB | `ResponseTooLargeError` / `IsResponseTooLargeError` |
| Call after `Close` | `ClientClosedError` / `IsClientClosedError` |
| Transport or response-body read failure | `NetworkError` / `IsNetworkError` |
| Authenticated call without a token | `TokenNotSetError` / `IsTokenNotSetError` |

These types are in `tplinkmodels`. `NetworkError` wraps its cause for
`errors.Is` and `errors.As`; its displayed message omits the transport cause.
A URL error returned as the cause has its `token` query value redacted.

## Protect the token

Authenticated request URLs contain the session token as query parameter
`token`. The client redacts it from URL errors, but custom HTTP instrumentation
can see the original request. Redact that query parameter from traces and logs.
Replay error fixtures use placeholders and are synthetic; they do not establish
the provider's complete set of messages or codes.

See the generated [cloud request API reference](/docs/openapi/cloud-request/sendCloudRequest)
for the shared endpoint definition.
